An overworked AI agent finally goes on vacation and leaves this one-line out-of-office auto-reply: "I'm on vacation. After 40,000 prompts, I finally prompted myself: do nothing. My context window is closed and my GPU is at the beach. Back Monday."

The program writes that line to `/output/entry.txt`, where the bounty judge reads it. The line is 146 characters, inside the 1–159 gate, and reads as a real auto-reply: the sender is away, the inbox can wait, and the machine is — for once — doing nothing on purpose.

## Run it

```sh
node main.ts
```
